COMP335 Final Idea

Proposed group project for the COMP335 final.

SetlistSync — Shared Charts & Rehearsal Hub

A collaborative web app for bands to share setlists, charts, song keys, and rehearsal takes in one place. Members upload sheet music or chord charts, mark the working key for each song, and attach practice recordings so everyone hears the same arrangement before the gig.

AI-assisted lyric and timing cues would help align words to rehearsal audio—useful for learning parts without building a full lyric-video product. The group would ship a Bootstrap grid UI, a REST API for bands/songs/takes, and a database for roles and setlist order. Stretch goals: key transpose helpers, comment threads on specific measures, and a live “tonight's set” view for the stage.
