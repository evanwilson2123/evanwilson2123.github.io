COMP335 Final Idea

Proposed group project for the COMP335 final.

CampusShift — Shared Study & Lab Scheduler

A web app where COMP335 groups can create courses, post available study or lab blocks, and claim seats for pair programming or review sessions. Students would authenticate, browse open slots on a shared calendar, request or offer help on specific topics, and leave short notes after each session so the next group knows what was covered.

Technically the team would use a Bootstrap-based responsive UI, a REST API for users/slots/bookings, and a relational database for schedules and attendance. Stretch goals include conflict detection when two overlapping slots are booked, and a simple matching view that suggests partners based on shared course tags—good practice for real group workflows and clean data modeling.
